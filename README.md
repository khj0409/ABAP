# ZBC405_18_ALVRE - SAP ABAP 리포트 프로그램

SAP 시스템에서 항공편 데이터를 조회하고, 다양한 조건별로 분석할 수 있는 ABAP 리포트 프로그램입니다.  
ALV Grid를 활용한 사용자 친화적 화면과 데이터 시각화, 실무에 가까운 다양한 기능을 제공합니다.

---

## 주요 기능

- **조건별 항공편 데이터 조회**  
  - 출발일, 항공편 번호 등 다양한 조건으로 SFLIGHT 테이블 데이터 조회
  - ALV Grid를 통한 테이블 형식 시각화 및 정렬/필터 기능

- **데이터 시각화**  
  - 좌석 점유율(seatsocc)에 따라 색상(빨강/노랑/초록)으로 상태 표시
  - 특정 항공기종(A380-800) 강조 색상 적용

- **사용자 맞춤형 레이아웃**  
  - 컬럼 숨김, 사용자별 레이아웃 저장 지원

- **상세 정보 팝업**  
  - 항공편 더블클릭 시 상세 정보 팝업 제공

- **Excel 연동**  
  - ALV 데이터를 Excel로 저장, 차트 생성

- **메시지 및 예외 처리**  
  - 총 7개의 메시지 코드 설계(오류, 경고, 정보)

---

## 설치 및 적용 방법

1. **패치 파일(Transport Request) 적용**
   - 첨부된 .cofile, .data 파일을 SAP 시스템에 업로드합니다.
   - SAP 트랜잭션 코드 `STMS`를 통해 트랜스포트 임포트

2. **직접 소스코드 적용**
   - SAP GUI에서 트랜잭션 코드 `SE38` 또는 `SE80` 실행
   - 새 프로그램 생성 후 소스코드 복사/붙여넣기

---

## 사용 방법

- SAP GUI에서 트랜잭션 코드 `ZCUST_SALES_REPORT` 입력 후 실행
- 검색 조건(고객코드, 기간 등) 입력 후 [실행] 버튼 클릭
- 결과 데이터 확인 및 Excel 다운로드 가능
- ALV Grid에서 행 더블클릭 시 상세 팝업 확인

---

## 주요 오브젝트/구조

- 프로그램명: `ZBC405_18_ALVRE`
- 테이블: `SFLIGHT`
- 메시지 클래스: `ZBC405_18`, `ZBC405_18ALV`
- 주요 화면: 0100, 0200, 0210
- 주요 이벤트: 더블클릭, 툴바 클릭 등
